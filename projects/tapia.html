The challenge

Challenge 8 asked us to design a study companion for students with different reading needs. Starting with chapter text, the app extracts key concepts and uses them to generate a concept map, a review sheet, and a quiz. Students can choose how the material is presented and revisit the topics they missed.

Building together in four hours

We split the work into reading the chapter, generating materials, grading answers, and building the interface. We agreed on a JSON format that gave each concept an ID. Sample questions let us work on the quiz screen and grading code before the generator was ready. Those same IDs connected the pieces when we put them together.

My contribution

I worked on the Python grading and memory logic and the Streamlit quiz interface. When a student submits an answer, we save its concept ID, result, and timestamp to a JSON file. The “Missed topics” screen reads the latest answer for each concept and selects practice questions from the current quiz.

Try a practice session

Paste a passage into the chapter text box, choose a reading mode, and select “Generate Study Materials.” Submit a quiz with one wrong answer, then open “Missed topics” in the sidebar.

Take the cell biology chapter in our repository. Suppose I answer the cell theory question correctly but miss one about prokaryotic cells. When I return to “Missed topics,” my practice quiz draws from the questions about prokaryotic cells. Once I answer correctly, that concept drops off my review list.

Learning modes

Standard mode uses paragraphs and a combined quiz. ADHD mode presents available notes one concept at a time, with a progress indicator. Dyslexia mode adjusts spacing and prompts the generator to use short sentences, bullets, and bold key terms. We presented the prototype to the Tapia judges. Testing these choices with students who use accommodations would be my next step.

What I learned

A quiz score alone can’t tell the interface what to show next. Working on both sides taught me why a shared concept ID matters. It connects a specific answer to the topic a student needs to revisit.
