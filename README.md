# My_Portfolio
Orkhan Guliyev Portfolio

A static portfolio covering data analysis, IT and networking, and campus leadership.

## Deploy on Netlify

Import this repository into Netlify and select the main branch. Leave the build command empty and use `.` as the publish directory. The homepage and assets are at the repository root.

## Local preview

Run `python3 -m http.server 8000` in the repository root, then open `http://localhost:8000/`.
